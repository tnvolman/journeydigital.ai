# Journal posts

Add a weekly post by dropping a markdown file in this folder.

- Filename becomes the URL slug: `my-post.md` → `/blog/my-post`
- Required frontmatter: `title`, `description`, `date` (`YYYY-MM-DD`)
- Body is standard markdown. Link consult CTAs to `/#contact`.

The index at `/blog` lists every `.md` file here, newest first.
